# myhne

AI-powered web application with chat, image generation, wallet connect, and credits management.

## Features

- AI Chat
- AI Image Generator
- Wallet Connect
- Credits Manager
- Mini-games
- Token buying and distribution

## Tech stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS and shadcn/ui

## Getting started

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 to use the app.

## Environment

Create a `.env.local` file with the required Nebius API key:

```
NEBIUS_API_KEY=your_api_key_here
```
